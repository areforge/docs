# AreForge Code Review

AreForge Code Review is an AI-powered code review service designed to help engineering teams review changes, identify potential issues, and improve code quality.

It integrates with your development workflow and brings automated code review into the merge request process.

## What you can do

- Automatically review merge requests
- Detect potential bugs and code quality issues
- Classify findings by severity
- Review large diffs through intelligent processing
- Integrate AI-powered review into your CI/CD workflow

## Documentation

This documentation covers installation, configuration, code review, AI agents, integrations, API usage, deployment, and contributing to AreForge.
